# spoti2yt(En)

This is a small tool to convert spotify song list to youtube song list.

 It mainly uses selenium and youtube api.

## Procedure

1.  Input song list
    - Input spotify song list
        - method=request(old)/selenium
    - Import from songlist.txt

---

2.  youtube playlist
    - Create yt playlist
    - Import existing playlist (enter yt link)

---

3.  Choose which song to start with

---

4.  Get song list

## How to use

 Well, because the youtube api is paid, there is no way for others to use it. This can be used as a code example.

 It's a bit tricky to use the youtube api ==
